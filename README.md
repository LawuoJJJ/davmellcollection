# davmellcollection
Davmell Collection

This is a Next.js project with Vercel Web Analytics integrated.

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Vercel Web Analytics

This project has been configured with Vercel Web Analytics. To enable analytics:

1. Deploy the project to Vercel
2. Go to your project's Analytics section in the Vercel dashboard
3. Click the "Enable" button to activate Web Analytics

The Analytics component is already integrated in `app/layout.tsx` and will automatically start tracking once enabled in your Vercel dashboard.

## Deploy on Vercel

Deploy this Next.js app using the [Vercel Platform](https://vercel.com/new).
